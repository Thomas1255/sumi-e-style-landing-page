# Flying with the flock

Nine ink-painted cranes fly through a sumi-e watercolor landscape using the four approved generated films. Each upscaled clip is 1918 × 1080, 24 fps, silent H.264. Rear-follow, left-bank, right-bank and high-overhead perspectives accompany the wetlands, terraces, forest and peaks respectively. Wings and poses come entirely from the films; the former jointed wing renderer is retained only as an unused historical study.

`dist/flight-timeline.js` shares landscape cuts and transition widths with `terrain.js`. Scroll position selects an exact source frame within each clip's landscape interval; the films stay paused, and queued seeks coalesce while scrolling quickly. Moving upward retraces the same frames. During each landscape dissolve the flock passes through mist, avoiding a superimposed double flock. Each perspective is positioned beside its own cloth panel. The second and third flocks hold that horizontal position and fade into the clouds instead of sliding across the screen before their transitions.

`dist/video-flock.js` removes the green video backing with a WebGL chroma key and edge despill, preserving the gray ink, ivory feathers and red crowns. Transparent approved PNGs appear while loading or when video/WebGL is unavailable. Reduced motion holds the first landscape and first video frame. No autoplay, audio track or external media service is required at runtime.

The opening rear-follow flock also travels gently into the valley as the first scene advances: its composition recedes by 14%, rises slightly and follows a restrained lateral curve. This movement comes from the same reversible scroll progress as the film. Mobile vertical travel is reduced to keep the flock below the cloth. The other three perspectives retain their existing placement, and reduced motion holds the opening composition still.

The background uses the four approved crane-matched views of one continuous sumi-e river valley: rear-follow wetlands, a leftward view across the village and golden terraces, a rightward view through the autumn temple forest, and a steep overhead gorge. Gates, bridges, towers and architecture share the original continuous master landscape's identity. The views are repainted perspectives rather than adjoining crops; independently painted sumi-e cloud layers bridge each camera change. The restrained painted dolly aims toward each flock's direction. The scenery stays a 2D ink-and-watercolor scroll.

Current terrain assets, approved PNGs, hashes and exact built-in ImageGen prompts are recorded in `art-previews/continuous-landscape-perspectives-v2/`. The original continuous master remains in `art-previews/continuous-landscape-v1/`, and earlier terrain artwork and prompts remain preserved. Runtime WebP copies keep the approved framing and dimensions. Approved transparent crane studies, source films, upscales, generation prompts and credit records remain in `art-previews/`. Seek-friendly web copies in `dist/assets/videos/` use six-frame keyframe spacing, no B-frames and MP4 fast-start metadata. The original upscales are preserved unchanged. `server.mjs` supports byte-range requests for efficient local seeking.

## Layered sumi-e cloud transitions

`dist/ink-clouds.js` animates the six approved transparent PNGs from `art-previews/sumi-cloud-transition-v2/`, preserved byte-for-byte in `dist/assets/clouds/`. Each side has its own rear, middle and foreground artwork with distinct silhouettes and brush patterns; no images are mirrored. Slow wisps arrive first, dense middle banks overlap across the scene cut, and larger foreground forms close and clear faster. Their separate scroll intervals and subtle vertical travel create depth without a timed playback animation.

All six positions follow the shared scene-cut centers, with a dedicated cloud window spanning 20% of the full scroll distance around each cut (about 2.1 times the landscape dissolve). Each layer eases its own movement over a linear scroll phase, avoiding the previous double easing that rushed the middle of the transition. The fully overlapped banks hold across 2.8% of the full scroll distance before reopening. Scrolling upward retraces them exactly, and jumping to a new position cannot leave an animation running. Responsive sizing crops the middle banks well beyond the viewport edges so their feathered leading edges overlap at the midpoint. The PNGs cover the terrain, cranes and cloth while navigation and flight controls stay accessible. Reduced motion hides this transition. It uses ordinary composited image layers, so it continues to work without WebGL; a warm loading veil only conceals a cut if the PNGs have not decoded or fail to load.

The page now starts with all six cloud banks fully closed. Scrolling through the first 5% of the journey gradually parts the foreground, middle and rear layers; scrolling back to the top closes them again. A small early loading cover prevents a flash of uncovered scenery before the PNGs decode. Normal-motion story sections have three times their former height, giving each later transition about three times its previous physical scroll distance. The opening cloth stays sticky so the title remains in view while the clouds part. Reduced motion reveals the page immediately and retains the shorter section heights.

Opening QA at 1280 × 720 measures about 769 CSS pixels for the introductory reveal and 3,075 for each later transition. At 390 × 844 each later transition spans about 3,756 pixels. Both viewports start fully closed, reveal the title without scrolling it away, clear after the intro, conceal all three scene cuts and return to the same cloud positions when scrolling back. No horizontal overflow or browser console errors/warnings were observed.

The existing Canvas UI ambient mist remains at its original gentle settings. It no longer swells into the old opaque procedural cloud wash. The original cloud renderer and earlier generated cloud studies remain preserved.

Cloud QA: desktop 1280 × 720 and mobile 390 × 844 confirm decoded PNGs, all three fully closed cuts, clear landscapes between cuts, identical transforms on reverse scrolling, no horizontal overflow and no console errors/warnings. Original-alpha coverage sampled every two CSS pixels measures at least 98% opacity throughout the closed viewport at 1280 × 720, 1920 × 1080, 2560 × 1080 and 390 × 844. Source hashes, measurements and approval are in the artwork record. Reduced motion is checked through the shared timeline and CSS rule; no OS preference was changed.

## Canvas UI Cloth

`dist/cloth.js` adapts the supplied Canvas UI Cloth implementation, retaining its wave equation, top pinning, foreshortening, mesh normals, directional light, sheen, shadow, and cursor imprint. Its grid is reduced from 96 to 56 subdivisions for multiple responsive panels.

`dist/page-cloth.js` paints the actual DOM layout into a canvas texture using text-node ranges and computed fonts. This replaces only the experimental HTML-in-canvas capture step so the same cloth mesh can run in standard browsers. Native text, headings, and links remain in the DOM for accessibility, selection and keyboard navigation. Focus switches to the native content for reliable visible keyboard interaction. A linen panel remains readable if WebGL or texture capture is unavailable.

The five story panels have an ivory woven linen finish, stitched hems, vermilion seals and dark wooden hanging rails. Wind, speed, amplitude, drape, brush, lighting and sheen retain the supplied demo settings. The fabric corner radius is reduced to suit a hanging scroll.

This integration reuses the already generated and upscaled clips. No further generation or upscale job was run.

Run `npm run dev` from the repository root and visit http://localhost:5173. `npm run build` verifies modules/assets, anchors, video frame bounds and reversibility, shared landscape transitions, all five cloth panels, reduced motion and real HTTP byte-range responses. Its HTTP check requires loopback access.

Visual QA covers desktop 1280 × 720 and mobile 390 × 844, all four video angles, transparent compositing, cloth legibility, and reverse seeking. Returning to the same slider position reproduces the same paused video time. The original right-bank film contains some edge crowding/cropping; this integration preserves that approved footage rather than inventing replacement birds.
