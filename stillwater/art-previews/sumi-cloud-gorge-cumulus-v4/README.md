# Gorge sky — regenerated cumulus cloud layers

Status: preview awaiting user approval. The live page and all current transition artwork are unchanged.

This replaces the proposed artwork for the final scene change only (68%, autumn temples to overhead gorge). The previous mountain plume set read as ocean waves when closed. Six new paintings use rounded luminous cloud volumes, pale cool-gray/celadon watercolor pockets, crisp painted grain and horizontal vapor fringes.

Created with built-in ImageGen. Every PNG has actual RGBA transparency, semi-transparent vapor edges and a dense painted body. All six content hashes are unique and the generated bytes are preserved unchanged. The first cloud was generated without image references; the other five used it only as a medium/palette reference with different silhouettes requested. No previous wave-like cloud image was supplied to generation.

The HTML compositions are static artwork studies for approval, using the new PNGs at their native aspect ratios. Runtime integration, choreography and responsive coverage tuning will follow approval.
