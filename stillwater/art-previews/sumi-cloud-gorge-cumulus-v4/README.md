# Gorge sky — regenerated cumulus cloud layers

Status: approved and implemented on 2026-10-29 following the user's “Implement this” request.

This replaces the artwork for the final scene change only (68%, autumn temples to overhead gorge). The previous mountain plume set read as ocean waves when closed. Six new paintings use rounded luminous cloud volumes, pale cool-gray/celadon watercolor pockets, crisp painted grain and horizontal vapor fringes. The old paintings are preserved in the original archive.

Created with built-in ImageGen. Every PNG has actual RGBA transparency, semi-transparent vapor edges and a dense painted body. All six content hashes are unique and the generated bytes are preserved unchanged. The first cloud was generated without image references; the other five used it only as a medium/palette reference with different silhouettes requested. No previous wave-like cloud image was supplied to generation.

The HTML compositions preserve the static artwork studies. Runtime copies are byte-for-byte identical to these approved PNGs in `stillwater/dist/assets/clouds/gorge-cumulus/`. The final transition selects those six sources at their original aspect ratios, with tuned overlaps, the existing staggered motion, long scroll span and sharper rendering. The opening and other two scene transitions are unchanged.

Coverage checks composite actual PNG alpha every 2 CSS pixels across the closed hold at 1280×720, 390×844 and 2560×1080; all sampled pixels are at least 98% opaque. Build checks validate native aspect ratios, all six approved content hashes, scene selection, exact reverse-scroll positions and reduced motion. Browser verification was unavailable because local browser use is disabled in Work settings.
