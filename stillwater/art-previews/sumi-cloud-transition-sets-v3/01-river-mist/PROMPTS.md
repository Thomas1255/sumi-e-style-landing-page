# River mist ribbons

Status: new artwork preview awaiting approval. Six independently generated transparent PNGs for the Wetlands to village scene change. The opening artwork and runtime animation are unchanged.

Built-in ImageGen was used for every asset. Only the approved landscape was supplied as a palette/medium reference. No earlier cloud was used as an input. Each original PNG is preserved unchanged.

Structure family: expansive HORIZONTAL RIVER MIST. Think long unequal ivory cloud ribbons, flat-topped lenticular overhangs, thin flowing mist fingers and delicate horizontal brush grain. Shadows are very pale celadon-gray, broken, watery and soft; no dark outline. The long layered bands and wispy split ends are the defining motif. No big spiral curls, scalloped rows, ocean crests or round cotton-ball clusters. This set should feel spacious, low, quiet and stretched by a gentle breeze.
