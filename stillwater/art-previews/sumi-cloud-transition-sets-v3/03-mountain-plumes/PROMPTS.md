# Mountain storm banks

Status: new artwork preview awaiting approval. Six independently generated transparent PNGs for the Autumn temples to overhead gorge scene change. The opening artwork and runtime animation are unchanged.

Built-in ImageGen was used for every asset. Only the approved landscape was supplied as a palette/medium reference. No earlier cloud was used as an input. Each original PNG is preserved unchanged.

Structure family: TALL WIND-TORN MOUNTAIN CLOUDS, monumental ragged vertical cloud plumes and downward fraying mist curtains. Cool slate-gray and diluted ink-blue shadow pools beneath luminous ivory faces; sharper broken vertical dry-brush texture contrasts with soft feathered vapor. Energetic height and irregular vertical rhythm define this set. These are atmospheric clouds, not rocks, triangular mountain peaks, smoke from a fire, water or waterfall. No circular spiral motifs, horizontal shelf stacks or ornamental scalloped chains.
