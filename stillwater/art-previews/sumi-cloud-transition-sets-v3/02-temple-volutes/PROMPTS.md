# Temple cloud scrolls

Status: new artwork preview awaiting approval. Six independently generated transparent PNGs for the Village to autumn temples scene change. The opening artwork and runtime animation are unchanged.

Built-in ImageGen was used for every asset. Only the approved landscape was supplied as a palette/medium reference. No earlier cloud was used as an input. Each original PNG is preserved unchanged.

Structure family: BOLD SCULPTURAL CLOUD VOLUTES inspired by neo-traditional Japanese painted cloud scrolls. Large generous rounded fan-lobes, open-ended spiral gestures and expressive curved dry-brush ink strokes. Luminous warm ivory masses, warm smoke-gray and faint muted taupe/ochre shadows. One or two decisive charcoal accents, not uniform cartoon outlines. A clear, elegant rhythmic curling silhouette. Distinct from flat horizontal mist ribbons and from ragged vertical storm pillars; no repetitive wave wallpaper.
