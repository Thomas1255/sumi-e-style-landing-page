# Sumi-e cloud transition artwork — v1

Status: preview awaiting user approval. These assets are not used by the site yet.

Two complementary transparent PNG cloud banks, generated with the built-in ImageGen tool. The left bank leads to the right; the right bank leads to the left. Warm ivory cloud bodies, muted gray/celadon ink washes and irregular brush edges match the approved landscapes.

The proposed animation is for the banks to move inward from both sides, overlap to cover a scene change, then reopen. Animation timing and viewport coverage remain to be implemented and checked after artwork approval.

## Left cloud bank

File: `cloud-left.png`

```text
Use case: stylized-concept
Asset type: transparent PNG transition cloud bank for a neo-traditional Japanese sumi-e watercolor landscape website.
Primary request: Paint ONE substantial LEFT-SIDE cloud bank that will slide horizontally from the left screen edge toward the center, eventually covering a scene cut together with a complementary right cloud bank.
Input image 1: style and palette reference ONLY, the existing painted landscape. Do not reproduce any scenery.
Style/medium: flat 2D Japanese sumi-e and restrained watercolor, handmade brushwork, graceful curling ink-cloud forms inspired by Japanese painted scrolls, soft diluted warm gray ink shading, faint dry-brush contour fragments. Cloud body is luminous warm ivory / rice-paper cream, with subtle cool gray and muted celadon undertones. No paper rectangle behind it.
Composition/framing: approximately square PNG canvas. An expansive layered cloud mass fills the ENTIRE LEFT edge, including top-left and bottom-left corners, and remains dense at top and bottom. Thick overlapping horizontal cloud lobes billow toward the RIGHT. The rightmost 15-25 percent has an irregular scalloped, wispy, organically feathered silhouette against true transparency. Broad continuous almost opaque ivory interiors occupy most of the left and middle, so the artwork can conceal the scenery. Left/top/bottom edges intentionally continue beyond the canvas; these are screen-edge covering assets, not an isolated small cloud icon. No transparent holes inside the dense cloud body. Tapered fine mist only along the leading right edge.
Constraints: actual transparent alpha background outside the cloud, preserve cloudy semi-transparent edge wisps. Use opacity in the ivory painted cloud itself; do not make the entire bank a translucent gray smear. Rich but restrained ink wash, calm, elegant scroll aesthetic matching the reference. No landscape, mountains, cranes, sky, horizon, sun, buildings, text, seals, labels, watermarks, checkerboard painting, black background, borders, photorealism, 3D volumetric rendering, cartoon puffball outlines, or gold ornament.
```

## Right cloud bank

File: `cloud-right.png`

```text
Use case: stylized-concept
Asset type: transparent PNG RIGHT-SIDE transition cloud bank, a matching partner to input image 1 for a sumi-e landscape website.
Primary request: Paint ONE RIGHT-SIDE cloud bank that will slide from the right screen edge toward the center. It must match the left cloud bank's warm ivory opaque body, soft gray/celadon ink wash, delicate broken contours, and flat Japanese scroll painting. Create complementary organically different lobes, not an exact mirror.
Input image 1: matching LEFT cloud bank reference for medium, color, density and scale. Input image 2: existing site's landscape for style and palette ONLY, no scenery to reproduce.
Composition/framing: approximately square PNG canvas. The cloud fills the ENTIRE RIGHT edge including top-right and bottom-right corners, extending beyond the right/top/bottom edges. Its vast dense body occupies the right and middle, and its irregular leading silhouette billows toward the LEFT with elegant broad horizontal lobes and a few soft curling wisps. The leftmost 15-25 percent opens to true transparency with feathered organic edges. Dense solid warm ivory interiors should conceal the scene behind; no gaps or transparent holes through the cloud's main body. Ensure substantial dense cloud reaches top and bottom. The opposing banks will overlap at screen center.
Style/medium: 2D neo-traditional Japanese sumi-e ink wash and watercolor on the cloud's painted surface, broad handmade brush textures, pale ivory masses, restrained warm-gray and muted celadon shading. Subtle elegant cloud curls rather than sharply outlined cartoon bubbles. Keep the same palette and airy-but-dense balance as image 1.
Constraints: actual transparent alpha background outside the cloud, fine semi-transparent edge mist, no background rectangle. No landscape, trees, birds, buildings, mountains, sky, horizon, sun, text, seals, labels, watermarks, painted checkerboard, black background, frame, 3D, photography, or gold ornament.
```
